Milion_A14_Phone (Android 14 / API 34, arm64, 1080×2400 @ 420 dpi = 411×914 dp, gesture navigation)
- Profile cold start to an interactive Today: trace 1,038 / 1,212 / 1,067 ms (engine enter → first frame rasterized, first frame deferred until content and image are ready); am start -W COLD 1,237–1,308 ms (median 1,276 ms; "Fully drawn" at the same instant). First launch to the first-run frame: 1,870 ms. See startup.json.
- First run: first-run.mp4 recorded with adb screenrecord after pm clear (launcher → splash → black → tessera → Milion pillar → street plan → coastline → rings I–IV → five places → "Every road started here." → Today).
- No permission prompt: after the first run and Today, dumpsys package app.milion shows android.permission.CAMERA granted=false; the only permission dialogs seen came from com.google.android.marvin.talkback (launchedFromPackage), not Milion.
- Predictive back (Settings.Global enable_back_animation=1): back on City returns to Today; the About page scales into the predictive-back preview of Today mid-gesture and pops; back on Today returns to the launcher (dumpsys: NexusLauncherActivity resumed). predictive-back-a14.mp4, device-predictive-back-peek-a14.png, device-back-to-home-a14.png.
- Edge-to-edge: device-today-a14.png — transparent status bar over the lamp strip with light icons, gesture handle over the marble navigation bar.
- TalkBack 16.0 (copied from the Pixel Fold system image, as the API 34 image has none): a fresh launch shows the spoken first run (one-sentence node + "Open Today"); activating the button under TalkBack lands on Today with focus on the first node; a TalkBack double-tap on the detail opens Milestone II at that detail. device-talkback-{first-run,today,detail}-a14.png. Speech output was not audited by ear; dial increase/decrease is covered by widget tests only.
- Found and fixed on the device: uiautomator toggles accessibility state, which flipped the first run between spoken and animated; modes are now one-way (test: "a screen reader arriving mid-sequence stays spoken") and the sentence and controls no longer overlap.
